# 사전 등록: 채널 관계 안정성 vs 섞기 이득 (2026-10-09, 계산 전에 작성·커밋)

## 왜
"한 공정/시스템을 측정하면 섞기가 이득"은 우리 데이터로 반증됨(ETT = 변압기 1대인데 손해, EWELD·Electricity = 별개 단위인데 이득;
`manuscript/notes/analysis_flow.md` 끝). 10-06 의 "연동 **강도**" 가설도 사전 규칙에서 실패(ρ 0.36). 남은 가설은 연동의
**안정성**: 학습 기간에 본 채널 관계가 시험 기간에도 유지되는 데이터일수록 섞기 이득이 크다(채널 독립이 분포 변화에 강하다는
선행 연구와 같은 방향). 이 검사는 **한 번만** 하고, 결과와 상관없이 그대로 보고한다. 지표를 바꿔 다시 하지 않는다.

## 측정
- 데이터 14개: 산업 6 (Steel · WindSCADA · BlastFurnace · N2O · MetroPT3 · EWELD) + LTSF 8 (ETTh1 · ETTh2 · ETTm1 · ETTm2 ·
  Weather · Exchange · Electricity · Traffic).
- 구간 = 실험과 같은 분할 (`utils/data_loader.py`): 학습 = 학습 구간 전체, 시험 = 시험 구간에서 입력 창(앞 96 행)을 뺀 부분.
  값은 로더가 만든 그대로(학습 통계로 표준화 — 상관에는 영향 없음). 산업 데이터의 채워 넣은 값(mask 0)은 빼고 관측값만,
  채널 쌍마다 둘 다 관측된 행으로 계산.
- 관계 변화량 S = 채널 쌍 (i < j) 의 **피어슨 상관 (시차 0)** 을 학습 구간과 시험 구간에서 각각 구해, |r_학습 − r_시험| 의 평균.
  어느 구간에서든 분산이 0 인 채널이 낀 쌍은 뺀다.
- 섞기 이득 G = FEATHer-CI 와 FEATHer-mix (동결 설정, L 96, 3 시드 평균) 의 칸별 % 변화 (CI − mix) / mix × 100 을
  4 H 에 대해 평균 (원고의 5.9 % 와 같은 규칙). 값 = `results/raw_{mfg,ltsf}.csv` main 행.

## 판정 (주)
14 개 데이터에서 S 와 G 의 스피어만 순위상관 ρ, 단측(음의 방향) p.
**ρ ≤ −0.5 이고 p < 0.05 → "가설과 일치"**, 아니면 **"안정성으로 설명되지 않음"**. 둘 다 원고에 그대로 쓴다.
"일치" 여도 상관관계이므로 원인이라고 쓰지 않는다 ("일치한다" 까지).

## 보조 (판정을 바꾸지 않음)
- ETT 4 개는 변압기 2 대에서 나와 독립이 아니다 → ETTh1+ETTm1, ETTh2+ETTm2 를 각각 S·G 평균으로 묶은 12 개로 같은 계산을 한 번 더 해
  결론이 같은지만 보고.
- 산업 6 개 / LTSF 8 개 각각의 S 범위를 표로만 보고 (검정 안 함).
